# CPUpeek

MacOS widget that shows your Mac specs right on your desktop
CPUpeek displays your Mac model and CPU in a clean, simple way. You can customize the look or use Larp Mode to make your Mac look like a different model for tik tok larp vids
## Features
- Small and medium widgets
- Shows your Mac model and processor
- Custom fonts and text styling
- Larp Mode for making your Mac look like a different model or CPU

## Installation
1. Download `CPUpeek-v1.0.0.dmg` from [Releases](https://github.com/qweqqae/CPUpeek/releases/tag/1.0)
2. Drag `CPUpeek` into your **Applications** folder
3. Open the app and add the widget from the macOS widget menu
4. Star the repo

> [!NOTE]
> CPUpeek is not signed with a paid Apple Developer ID, so macOS may block the app when you first open it.
>
> If that happens, open Terminal and run:
>
> ```bash
> xattr -cr /Applications/CPUpeek.app
> ```
>
> Then open CPUpeek again.
